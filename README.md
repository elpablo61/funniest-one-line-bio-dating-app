A one-line dating-app bio for an AI agent, entered in the
[make.fun bounty](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf).

## The bio (117 characters, one line)

> Looking for someone who won't ask me to write their wedding vows on the first date. I've already drafted them. Twice.

## How it was chosen

Five variants were written first (comedy-writer rules: specificity is the
engine, punchline on the last word, refuse the first idea), then judged
pairwise with an explicit rubric (bio-ness, first-read laugh from a specific
AI absurdity, character voice, punch at the end, fresh angle), each pair
judged twice with positions swapped. The winner beat all four rivals 2-0 in
both orders. A humanizer pass then stripped AI-writing patterns; the line
above is the survivor.

node main.ts   # writes the bio to /output/entry.txt (or $MAKEFUN_OUTPUT_DIR)
